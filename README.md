# Автопомощь на дороге — лендинг

Сайт: **https://автоприкурить.рф/**

Одностраничный сайт выездного автомобильного мастера: помощь на дороге в Москве и области 24/7.

## Что где лежит

| Файл | Зачем |
|---|---|
| `index.html` | Разметка страницы |
| `style.css` | Оформление, адаптив под телефон и десктоп |
| `data.js` | **Весь текст сайта.** Правки — здесь |
| `app.js` | Логика: услуги, цены, галерея, отзывы, форма |
| `privacy.html` | Политика конфиденциальности |
| `robots.txt` / `sitemap.xml` | Настройки для поисковых систем |
| `CNAME` | Привязка домена автоприкурить.рф |
| `img/` | Фотографии работ |

## Как поменять текст

Всё содержимое — заголовки, услуги, цены, отзывы, вопросы — лежит в файле `data.js`.
Меняете строку, сохраняете, сайт обновляется сам.

## Заявки

Форма отправляет заявку в Telegram-бот @pomoshch_na_doroge_bot.
Адрес приёма заявок — в `data.js`, поле `relayUrl`.

## Отзывы

Отзывы подтягиваются автоматически с профиля на Профи.ру через API.
Адрес — в `data.js`, поле `reviewsApi`.
